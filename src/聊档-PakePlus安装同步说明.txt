聊档｜PakePlus 电脑手机同步版
==========================

✅ 你可以继续使用现在的 PakePlus，不需要安装 Python、Node.js、Android Studio，
   也不需要部署 Netlify 网站。

【先保护旧资料】
如果旧版聊档已经保存了数据，请先打开旧版软件，点击“导出备份”，保存 JSON 文件。
升级重新打包后，即使软件标识相同，原来的本地数据也不保证自动保留！

【第 1 步：把新版文件放进 PakePlus】
1. 解压整个 ZIP。
2. 打开 PakePlus 里你截图上的“聊档 → 软件配置”页面。
3. 在“网站地址”旁边点击上传按钮，选择解压后的“PakePlus上传此文件夹”。
   这个文件夹里已经包含 index.html 和 icon.png。
4. 软件名称：聊档；软件标识：liaodang（尽量保持原值）；
   软件版本：建议从 0.0.1 改成 0.0.2。
5. 点“保存 → 预览 → 发布”，分别生成电脑和安卓的安装包。
   iPhone 如果需要原生 APP，请按 PakePlus 支持的 iOS 打包流程操作。

【第 2 步：启用一次云端（真正跨设备同步必需）】
PakePlus 负责安装 APP，本身不提供两台设备共用的数据存储。
因此，第一次使用需要有一个云端数据库；后续就不必反复设置。

1. 在浏览器打开 https://supabase.com/dashboard ，创建个人项目。
2. 在 Supabase 的 SQL Editor 中，复制“云端初始化.sql”的全部内容，
   执行一次，建立私人聊天资料表和私有附件存储桶。
3. 在项目设置的 API Keys 页面找到：
     Project URL，格式类似 https://xxxx.supabase.co
     Publishable key，格式类似 sb_publishable_...
   旧项目也可使用 anon key。
   绝对不要把 secret / service_role key 输入聊档！
4. 打开电脑上的新版聊档 → 右上角“☁ 云同步”。
5. 填入 Project URL 和 Publishable key → “保存云服务设置”。
6. 用个人邮箱“注册新账号”或登录。若开启了邮箱验证，先点邮件中的验证链接，
   再回到聊档登录即可。
7. 如果旧版有资料，先登录再“导入旧版备份 JSON”，点击“立即同步”。
   资料多或有图片时，先等同步完成再退出软件。

【第 3 步：手机同步电脑数据】
1. 手机安装同一版聊档 APP。
2. 电脑端“云同步”中点“复制配置码到手机”，把代码发给自己。
3. 手机端“云同步”中点“粘贴另一设备的配置码”，填入刚才的代码。
4. 使用与电脑端完全相同的聊档登录邮箱和密码。
5. 点“立即同步”，即可获取相同资料。之后在软件打开且联网时自动尝试同步。
   两台设备无需接同一 Wi-Fi，但都需要连接互联网。

【已实现】
- 文字版聊天记录上传与全文搜索、命中行定位
- 标题、分类、标签、归档、收藏、笔记、视频链接同步
- 图片和 PDF 原始附件的私有云上传和跨设备下载
- 同名视频文件识别：只同步文件名索引、大小和备注，不同步视频本体
- 本地数据缓存、离线保存待同步、更改同步、删除同步
- 备份 JSON 导入/导出、迁移旧版聊档

【重要限制】
- 未连接云端时：仍能本地使用，但电脑和手机不会自动共享资料。
- 同步不是 APP 关闭后持续进行的后台服务；请联网打开 APP 让它完成同步。
- 两台设备同时编辑同一记录采用时间较新的版本，不做逐句合并。
- 扫描版 PDF 和图片暂不自动 OCR；可手工补录可搜索文字。
- PDF 文字层提取可能需要联网加载 PDF.js，失效时仍可上传 PDF 附件。
- 视频文件只做文件名索引，不上传大视频、也不提取视频内容。
- 聊天资料保存在自己创建的 Supabase 项目，数据不是端到端加密。
  请使用强密码、注意隐私、定期导出备份。
- 已在两个独立浏览器会话和模拟云 API 中测试同步流程；
  未在你的 PakePlus 安装环境或真实 Supabase 项目上做联网联调。

【如果提示错误】
- 登录后提示表或函数不存在：请检查是否执行“云端初始化.sql”。
- “权限不足”：请确认 SQL 成功创建私有桶和 RLS 权限策略。
- 手机无记录：确认两个 APP 指向同一个 Supabase 项目且登录同一个聊档账号，
  再分别点一次“立即同步”。
- 旧资料看不到：到旧版导出 JSON，在新版登录后导入。
- 如果 PakePlus 特定打包模式限制外部请求，需在其设置中允许联网访问；
  本 HTML 不需要额外 JS 安装，但云同步需要连接 Supabase 的 HTTPS API。

PakePlus 本地 HTML 打包官方说明：https://www.pakeplus.com/question/html
Supabase 项目管理入口：https://supabase.com/dashboard
